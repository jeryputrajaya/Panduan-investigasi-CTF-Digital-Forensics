01

file

— Deteksi Tipe Asli Berkas

Wajib Awal
Sintaks siap pakai 
$file -b -i misteri_file
Fungsi & penjelasan opsi
  • file: Membaca Magic Bytes di awal berkas untuk menentukan format asli tanpa peduli ekstensi namanya.
  • -b (brief): Menampilkan hasil secara ringkas tanpa mengulang nama file.
  • -i (mime): Menampilkan tipe MIME (mis. image/png, text/plain) beserta charset-nya.
Kapan dipakai · Selalu jalankan pertama kali pada setiap file soal, terutama file tanpa ekstensi (bernama file atau data.bin) atau file yang gagal dibuka.
Kombinasi piping 
$find . -maxdepth 3 -type f | xargs file -i | grep -v "text/plain"

Memindai seluruh file di direktori hingga kedalaman 3 folder dan menyaring file biner non-teks.

02

exiftool

— Ekstraksi Metadata & Tag Tersembunyi

Metadata
Sintaks siap pakai 
$exiftool -a -u -g1 gambar.jpg
Fungsi & penjelasan opsi
  • -a (allow duplicates): Menampilkan seluruh tag metadata meskipun memiliki nama duplikat.
  • -u (unknown): Menampilkan tag kustom atau tidak standar yang sering disisipkan pembuat soal.
  • -g1 (group): Mengelompokkan metadata berdasarkan kategori lokasi (EXIF, XMP, File, Composite).
Kapan dipakai · Soal melibatkan foto kamera, PNG, PDF, atau audio dengan petunjuk seperti "who took this photo?", "check author/GPS", atau ukuran file sedikit lebih besar dari resolusinya.
Kombinasi piping 
$exiftool -a -u target.png | grep -iE "flag|ctf|pico|academy|comment|description|author|warning"

Menyaring langsung baris metadata yang paling sering berisi petunjuk atau potongan flag.

03

xxd / hexdump

— Inspeksi Byte Hexadecimal & ASCII

Hex Analysis
Sintaks siap pakai 
$xxd -l 64 -g 1 berkas_rusak.png
$hexdump -C -n 64 berkas_rusak.png
Fungsi & penjelasan opsi
  • -l 64 / -n 64: Membatasi output hanya 64 byte pertama agar layar terminal tidak penuh.
  • -g 1 (groupsize): Mengelompokkan tampilan per 1 byte (2 digit hex) agar pencocokan Magic Bytes sangat jelas.
  • -C (canonical): Menampilkan kolom hex sekaligus terjemahan ASCII di sisi kanan pada hexdump.
Kapan dipakai · Output file hanya bertuliskan data, muncul error "unsupported image format", atau mengecek apakah ada data tambahan setelah footer file (IEND / FF D9).
Kombinasi piping 
$xxd target.png | tail -n 15

Memeriksa 15 baris terakhir file untuk melihat apakah ada teks atau file lain setelah penutup IEND.

04

dd + printf / hexedit

— Perbaikan Header Rusak

File Repair
Sintaks siap pakai 
$printf 'ÿØÿà' | dd of=rusak.jpg bs=1 seek=0 count=4 conv=notrunc
$hexedit rusak.jpg
Fungsi & penjelasan opsi
  • printf 'ÿØ...': Mencetak byte mentah heksadesimal (contoh di atas untuk memperbaiki header JPEG).
  • bs=1 seek=0 count=4: Menulis tepat 4 byte mulai dari posisi byte ke-0 (awal file).
  • conv=notrunc: Sangat krusial! Mencegah dd memotong sisa isi berkas setelah byte yang ditimpa.
  • hexedit: Editor hex interaktif di terminal (ketik hex baru, lalu tekan Ctrl+X dan Y untuk menyimpan).
Kapan dipakai · Soal berjudul "Corrupted file" atau file gambar/arsip memiliki byte awal yang diubah menjadi nol atau karakter acak.
Kombinasi piping 
$printf 'PNG
$
$' | dd of=fix.png bs=1 seek=0 count=8 conv=notrunc && file fix.png

Memperbaiki 8-byte signature PNG secara otomatis lalu langsung memverifikasi hasilnya dengan file.

05

pngcheck

— Validasi Chunk & Dimensi PNG

PNG Forensics
Sintaks siap pakai 
$pngcheck -vtp7f gambar.png
Fungsi & penjelasan opsi
  • -v (verbose): Menampilkan rincian offset setiap chunk (IHDR, IDAT, tEXt, IEND).
  • -t (text): Menampilkan isi seluruh chunk komentar teks di dalam PNG.
  • -p & -7: Menampilkan informasi palet dan karakter non-ASCII secara aman.
  • -f (force): Tetap melanjutkan inspeksi meskipun ditemukan CRC checksum error.
Kapan dipakai · Bagian bawah gambar PNG tampak terpotong (nilai Height pada chunk IHDR sengaja dikecilkan pembuat soal) atau muncul galat CRC.
Kombinasi piping 
$pngcheck -v target.png | grep -iE "CRC|IHDR|tEXt|error"

Menyoroti chunk yang rusak, nilai dimensi asli, dan pesan teks tersembunyi di struktur PNG.

06

pdftotext / qpdf

— Bedah Dokumen & Stream PDF

PDF Forensics
Sintaks siap pakai 
$pdftotext dokumen.pdf -
$qpdf --qdf --object-streams=disable dokumen.pdf unpacked.pdf
Fungsi & penjelasan opsi
  • pdftotext ... -: Mengekstrak seluruh lapisan teks di dalam PDF langsung ke stdout terminal (-), menembus kotak hitam penutup teks.
  • qpdf --qdf: Mendekompresi stream biner internal PDF agar objek tersembunyi bisa dibaca dengan strings atau grep.
Kapan dipakai · Soal berupa dokumen PDF dengan bagian teks yang disensor kotak hitam, teks berwarna putih di atas latar putih, atau gambar berlapis di dalam PDF.
Kombinasi piping 
$pdftotext dokumen.pdf - | grep -iE "flag|ctf|pico|academy|\{.*\}"

Mengekstrak teks tersembunyi di balik sensor PDF dan langsung menyaring format flag.

07

stat

— Analisis Stempel Waktu (MACB)

Timeline
Sintaks siap pakai 
$stat berkas_target
Fungsi & penjelasan opsi
  • stat: Menampilkan informasi inode, ukuran blok, izin akses, serta timestamp lengkap (Access, Modify, Change, Birth) hingga presisi nanodetik.
Kapan dipakai · Terdapat ratusan file identik di dalam folder dan soal menanyakan file mana yang terakhir disentuh/dimodifikasi, atau flag dikodekan pada angka milidetik timestamp.
Kombinasi piping 
$stat -c "%y %n" * | sort -r | head -n 10

Mengurutkan seluruh berkas di direktori berdasarkan waktu modifikasi paling baru lengkap dengan nanodetik.

08

ent

— Analisis Tingkat Keacakan Data

Entropy Check
Sintaks siap pakai 
$ent berkas_misterius.bin
Fungsi & penjelasan opsi
  • ent: Menghitung entropy (skala 0–8 bit per byte) dan uji statistik Chi-Square suatu berkas untuk menilai seberapa acak isinya.
  • Entropy mendekati 8.0: menandakan data terenkripsi, terkompresi, atau sudah memuat steganografi rapat — distribusi byte-nya nyaris seragam sempurna.
  • Entropy jauh di bawah 8.0 (misalnya 4–6): menandakan teks, kode, atau gambar mentah yang belum diproses, sehingga payload tersembunyi dengan LSB klasik lebih mungkin ditemukan.
Kapan dipakai · Jalankan sebelum memilih strategi lanjutan, untuk memutuskan apakah berkas layak dicoba dibongkar passphrase-nya atau cukup di-decode dengan strings/base64, serta untuk menandai segmen anomali di tengah berkas gabungan.
Kombinasi piping 
$for f in extracted_*/*; do echo -n "$f: "; ent "$f" | grep 'Entropy ='; done

Memindai entropy seluruh berkas hasil carving sekaligus, agar kandidat berkas terenkripsi atau arsip tersembunyi cepat terlihat.

09

compare (ImageMagick)

— Diffing Visual Dua Berkas Serupa

Image Diff
Sintaks siap pakai 
$compare asli.png modifikasi.png -highlight-color red diff_hasil.png
Fungsi & penjelasan opsi
  • compare: Bagian dari paket ImageMagick, membandingkan dua gambar piksel demi piksel dan menghasilkan peta perbedaan visualnya.
  • -highlight-color red: menandai setiap piksel yang berbeda dengan warna merah agar langsung terlihat oleh mata.
  • Versi numerik: compare -metric AE asli.png modifikasi.png null: 2>&1 mencetak jumlah total piksel yang berbeda tanpa membuat gambar output.
Kapan dipakai · Soal memberikan dua berkas gambar yang terlihat identik sekilas, misalnya bernama before.png & after.png, atau original & edited — flag biasanya disisipkan sebagai perubahan piksel kecil yang tidak kasat mata.
Kombinasi piping 
$compare asli.png modifikasi.png -metric AE -fuzz 5% diff.png; identify -verbose diff.png | grep -i 'geometry'

Membuat peta perbedaan dengan toleransi noise 5% lalu langsung memeriksa statistik geometri area yang berubah.

01

strings

— Ekstraksi Teks dari Berkas Biner

Wajib Awal
Sintaks siap pakai 
$strings -n 6 -e s target.bin
$strings -n 6 -e l windows_dump.bin  # UTF-16LE (Windows)
Fungsi & penjelasan opsi
  • -n 6: Hanya menampilkan urutan teks minimal 6 karakter untuk membuang karakter sampah biner.
  • -e s: Encoding 7/8-bit ASCII standar. Gunakan -e l untuk teks 16-bit Little Endian (sangat sering ditemukan pada memory dump & executable Windows).
Kapan dipakai · Langkah wajib setelah file dan exiftool pada seluruh berkas biner, gambar, PCAP, maupun memory dump.
Kombinasi piping 
$strings -n 5 target.bin | grep -iE "flag|ctf|pico|academy|htb|\{.*\}"

Langsung menyaring kata kunci flag atau pola kurung kurawal dari jutaan baris string biner.

02

grep

— Pencarian Regex & Rekursif

Filtering
Sintaks siap pakai 
$grep -rnEoa "[a-zA-Z0-9_]+\{[a-zA-Z0-9_@!?-]+\}" ./folder_ekstrak/
Fungsi & penjelasan opsi
  • -r (recursive): Memindai seluruh file di dalam folder dan subfoldernya.
  • -n: Menampilkan nomor baris tempat pola ditemukan.
  • -E: Mengaktifkan Extended Regular Expression.
  • -o (only-matching): Hanya mencetak potongan teks yang cocok dengan pola (mencegah terminal macet jika flag berada di 1 baris berisi 1 juta karakter).
  • -a (text): Memperlakukan file biner seolah-olah file teks.
Kapan dipakai · Setelah mengekstrak arsip berisi ratusan file log, kode sumber, atau direktori hasil mount disk image.
Kombinasi piping 
$strings -n 6 dump.raw | grep -i -C 3 "password"

Menampilkan kata password beserta 3 baris sebelum dan sesudahnya (-C 3) untuk membaca konteks kredensial.

awk / tr / rev / uniq

— Manipulasi & Pembersihan Teks

Text Wrangling
Sintaks siap pakai 
$awk '{print $NF}' kolom.txt | tr -d '
$
$ ' | rev
Fungsi & penjelasan opsi
  • awk '{print $NF}': Mengambil kolom paling terakhir dari setiap baris.
  • tr -d ' ': Menghapus newline dan spasi agar pecahan karakter menyatu menjadi satu string utuh.
  • rev: Membalik urutan karakter per baris (mis. }galf{FTC → CTF{flag}).

Kombinasi piping 
$sort log_besar.txt | uniq -c | sort -n | head -n 10

Menampilkan 10 baris paling langka/unik di dalam file log raksasa.

base64 / xxd -r -p

— Decoding Base64, Base32 & Hex

Decoding
Sintaks siap pakai 
$base64 -d payload.b64 > hasil.bin && file hasil.bin
$echo "61636164656d797b6865787d" | xxd -r -p; echo ""
Fungsi & penjelasan opsi
  • base64 -d / base32 -d: Mendekode data tersandi Base64/Base32 kembali ke bentuk teks atau file biner aslinya.
  • xxd -r -p: Melakukan reverse (-r) dari format plain hex dump (-p) menjadi byte/teks asli.
  • Format lain yang sering muncul berdampingan: base32 -d untuk Base32, basenc --base32 -d pada sistem yang tidak punya base32 tersendiri, serta decoder Base58/Base85 biasanya ditangani lewat skrip python3 singkat.
Kapan dipakai · Menemukan blok teks panjang berakhiran = (Base64/32) atau deretan string heksadesimal panjang seperti pada bilah bawah gambar Flag in Flame.
Kombinasi piping 
$cat hex_panjang.txt | tr -d ' 
$' | xxd -r -p > out.bin && file out.bin

Membersihkan spasi/baris baru pada string hex lalu mengubahnya menjadi berkas biner dan langsung mengecek formatnya.

05

tesseract

— Ekstraksi Teks dari Gambar (OCR)

Optical OCR
Sintaks siap pakai 
$tesseract gambar_teks.png stdout --psm 6
Fungsi & penjelasan opsi
  • tesseract: Mesin Optical Character Recognition (OCR) untuk membaca tulisan yang tercetak di dalam gambar.
  • stdout: Mencetak hasil pembacaan langsung ke terminal tanpa membuat file .txt baru.
  • --psm 6 / --psm 7: Mengatur mode segmentasi halaman (6 untuk blok teks seragam, 7 untuk satu baris teks tunggal).

Kombinasi piping 
$convert full.png -gravity South -crop 100%x8%+0+0 -negate bar.png && tesseract bar.png stdout --psm 7

Memotong 8% bagian paling bawah gambar, membalik kontras warnanya, dan langsung membaca teksnya dengan OCR.

06

python3 (One-Liner)

— Decoder Biner, ROT13 & Bitwise XOR

Swiss Army Knife
Sintaks siap pakai 
$python3 -c 'import codecs; print(codecs.decode("synt{ebg13}", "rot_13"))'
$python3 -c 'a=b"YO[\N\ME"; b=b"8,:8+14>"; print(bytes(x^y for x,y in zip(a,b)))'
Fungsi & penjelasan opsi
  • python3 -c '...': Mengeksekusi logika kriptografi atau konversi bit secara instan di terminal.
  • x ^ y: Operasi Bitwise XOR antar dua string atau brute-force kunci XOR 1-byte (range(256)).
Kapan dipakai · File berisi teks biner 0 dan 1 (seperti digits.bin), sandi ROT13, atau payload yang disamarkan dengan operasi XOR (seperti pada Very very very Hidden).
Kombinasi piping 
$tr -d ' 
$' < digits.bin | python3 -c 'import sys; d=sys.stdin.read(); sys.stdout.buffer.write(int(d,2).to_bytes(len(d)//8,"big"))' > out.jpg && file out.jpg

Mengubah deretan teks karakter 0 dan 1 menjadi file biner asli (JPEG/PNG) dalam satu baris perintah.

07

xortool

— Mencari Kunci XOR yang Tidak Diketahui

XOR Cracking
Sintaks siap pakai 
$xortool -l 6 -c 20 payload_terenkripsi.bin
Fungsi & penjelasan opsi
  • xortool: Menebak panjang kunci XOR berulang dengan menganalisis byte yang paling sering muncul, berasumsi plaintext asli mengandung banyak byte 0x00 atau spasi.
  • -l 6: Memaksa pencarian hanya pada panjang kunci 6 byte; kosongkan agar otomatis mencoba 1 sampai 32.
  • -c 20: Memberi tahu bahwa karakter paling umum pada plaintext asli adalah byte 0x20 (spasi), sehingga kalkulasi kunci menjadi lebih akurat.
Kapan dipakai · Berkas biner hasil ekstraksi tidak cocok dengan tipe apa pun menurut file, tetapi entropy-nya sedang (bukan terenkripsi penuh) — ciri khas data yang disamarkan dengan satu kunci XOR berulang.
Kombinasi piping 
$xortool-xor -s 'flag{' -f payload.bin | head -c 40

Mencari posisi dan kunci XOR dengan mengasumsikan hasil akhirnya pasti memuat potongan teks "flag{" yang sudah diketahui sebelumnya (known-plaintext attack).

Steganografi (Gambar, Lapisan Piksel & Audio)

Mendeteksi dan mengekstrak pesan, skrip, maupun file yang disisipkan di balik bit piksel warna (LSB/MSB), koefisien JPEG, maupun frekuensi spektrum suara.

01

zsteg

— Deteksi LSB/MSB Otomatis (PNG & BMP)

Image Stego
Sintaks siap pakai 
$zsteg -a gambar.png
$zsteg -E "b1,rgb,lsb,xy" gambar.png > extracted_payload.bin
Fungsi & penjelasan opsi
  • -a (all): Menguji seluruh kombinasi bit (LSB/MSB), urutan kanal (RGB/BGR/RGBA), dan arah pemindaian piksel.
  • -E "..." (extract): Mengekstrak payload mentah dari kanal spesifik yang terdeteksi ke dalam file baru.
Kapan dipakai · Berkas berformat .png atau .bmp dengan kata kunci "pixels", "bits", "invisible", atau "LSB".
Kombinasi piping 
$zsteg -a gambar.png | grep -iE "text|flag|ctf|pico|academy|zip|elf|powershell"

Menyaring hasil ratusan kombinasi bit agar hanya menampilkan temuan yang bermakna.

02

convert (ImageMagick)

— Konversi Lossless & Pisah Kanal Warna

Bit-Plane Fix
Sintaks siap pakai 
$convert output.bmp output.png && zsteg -a output.png
$convert gambar.png -separate channel_%d.png
Fungsi & penjelasan opsi
  • convert output.bmp output.png: Mengatasi galat dib_hdr_size 124 unsupported pada zsteg dengan mengonversi BMP Windows V5 menjadi PNG secara lossless.
  • -separate: Memisahkan gambar menjadi lapisan kanal Merah (0), Hijau (1), dan Biru (2) untuk inspeksi visual pengganti Stegsolve.
Kapan dipakai · zsteg mengalami crash saat membaca file .bmp modern, atau saat ingin melihat tulisan tersembunyi pada satu kanal warna tertentu.
Kombinasi piping 
$convert gambar.png -channel R -separate -threshold 50% red_plane.png && xdg-open red_plane.png

Mengekstrak lapisan warna merah dengan ambang kontras tinggi untuk memunculkan teks tersembunyi.

Brute-Force

05

python3 (PIL / PSImage)

— Ekstraktor 4-Bit Nibble (Blue & Green)

Advanced Stego
Sintaks siap pakai 
$python3 -c 'from PIL import Image; im=Image.open("evil_duck.png"); px=list(im.getdata()); out=bytes(((b&15)<<4)|(g&15) for r,g,b,*_ in px); open("ps_script.bin","wb").write(out)' && strings -n 8 ps_script.bin | head
Fungsi & penjelasan opsi
  • ((b & 15) << 4) | (g & 15): Mengambil 4 bit terbawah kanal Biru sebagai upper nibble dan 4 bit terbawah kanal Hijau sebagai lower nibble (ciri khas tool Invoke-PSImage).
Kapan dipakai · Gambar PNG memiliki selisih nilai piksel maksimal 15 (4-bit) dibanding gambar asli, atau ditemukan petunjuk powershell pada PCAP/log (seperti soal Very very very Hidden).
Kombinasi piping 
$strings -n 6 ps_script.bin | grep -iE "flag|ctf|academy|bxor|string"

Langsung memeriksa variabel dan operasi XOR di dalam skrip PowerShell yang berhasil diekstrak dari piksel gambar.

06

sox & zbarimg

— Spektrogram Audio & Pembaca QR Code

Audio & QR
Sintaks siap pakai 
$sox suara.wav -n spectrogram -o spektrogram.png
$zbarimg -q --raw qr_flag.png
Fungsi & penjelasan opsi
  • sox ... -n spectrogram: Merender gelombang frekuensi audio ke gambar PNG sehingga tulisan flag yang digambar di frekuensi tinggi terlihat jelas.
  • zbarimg -q --raw: Memindai dan mencetak isi QR Code atau Barcode mentah langsung di terminal.
Kapan dipakai · Berkas audio terdengar berdesis/beep aneh di nada tinggi, atau hasil pemisahan kanal gambar menghasilkan QR Code (termasuk yang warnanya terbalik).
Kombinasi piping 
$sox suara.wav -n remix 1 spectrogram -o ch1.png && convert inverted_qr.png -negate fixed.png && zbarimg --raw fixed.png

Membuat spektrogram khusus kanal audio kiri (remix 1) dan membaca QR Code yang warnanya dinegasikan.

07

ffmpeg / ffprobe

— Bedah Frame Video & Audio Tersembunyi

Video Forensics
Sintaks siap pakai 
$ffmpeg -i video_mencurigakan.mp4 -vf fps=1 frame_%04d.png
Fungsi & penjelasan opsi
  • ffmpeg: Mengekstrak setiap frame video menjadi gambar diam agar dapat dipindai satu per satu dengan zsteg/strings, atau diperiksa manual mencari QR Code maupun teks sekilas.
  • -vf fps=1: Mengambil satu frame setiap satu detik durasi video; perbesar angkanya (misalnya fps=10) untuk sampling yang lebih rapat.
  • ffprobe -show_streams -show_format video.mp4: Menampilkan metadata lengkap berupa codec, durasi, serta stream tersembunyi atau subtitle sebelum ekstraksi dimulai.
Kapan dipakai · Soal memberikan berkas video (.mp4, .mkv, .avi) — flag sering disembunyikan pada satu frame spesifik, pada track audio kedua, atau pada metadata container itu sendiri.
Kombinasi piping 
$ffmpeg -i video.mp4 -vf fps=1 frame_%04d.png && zbarimg frame_*.png 2>/dev/null | grep -i 'QR-Code'

Mengekstrak seluruh frame lalu langsung memindai setiap gambar untuk mencari QR Code yang mungkin hanya muncul sekilas.

08

stegolsb (wavsteg)

— LSB Steganografi pada Audio WAV

Audio Stego
Sintaks siap pakai 
$stegolsb wavsteg -r -i suara_curiga.wav -o hasil_lsb.txt -n 1
Fungsi & penjelasan opsi
  • stegolsb: Tool Python untuk membaca atau menulis data pada bit paling tidak signifikan (LSB) tiap sampel audio WAV, cara kerjanya mirip zsteg namun khusus audio.
  • wavsteg -r: Mode reveal alias ekstraksi, kebalikan dari mode -h (hide) untuk menyembunyikan data.
  • -n 1: Jumlah bit LSB yang dibaca dari setiap sampel; coba naikkan bertahap ke 2, 3, atau 4 jika hasil pertama berupa data sampah.
Kapan dipakai · Berkas audio berformat .wav saja — bukan .mp3, karena kompresi lossy pada MP3 merusak data LSB — yang berukuran tidak wajar besar untuk durasinya, atau soal secara eksplisit menyebut "dengarkan baik-baik".
Kombinasi piping 
$stegolsb wavsteg -r -i suara.wav -o out.bin -n 2 && file out.bin && strings out.bin | grep -i flag

Mengekstrak 2-bit LSB dari setiap sampel lalu langsung memeriksa apakah hasilnya berupa berkas lain atau teks flag.

Tahap 04

File Carving, Ekstraksi Berkas Tertanam & Perbaikan Arsip

Memisahkan berkas yang digabungkan menjadi satu file, memulihkan data terhapus dari raw image, serta menangani arsip kompresi berlapis atau rusak.

01

binwalk

— Pemindaian & Ekstraksi File Tertanam

Carving Utama
Sintaks siap pakai 
$binwalk -e --dd=".*" gambar_mencurigakan.png
Fungsi & penjelasan opsi
  • -e (extract): Mengekstrak otomatis semua signature berkas yang dikenali ke folder _namafile.extracted/.
  • --dd=".*": Memaksa carving seluruh jenis signature yang ditemukan di dalam berkas.
Kapan dipakai · Ukuran berkas gambar/audio jauh lebih besar dari wajarnya, atau sebagai pengecekan wajib pada setiap file media.
Kombinasi piping 
$binwalk target.png | grep -vE "Zlib|TIFF"

Menyaring blok kompresi Zlib bawaan PNG agar hanya signature file tambahan yang terlihat.

02

foremost / scalpel

— Carving Berbasis Header & Footer

Deep Carving
Sintaks siap pakai 
$foremost -i gabungan.bin -o hasil_carve/
Fungsi & penjelasan opsi
  • -i: Berkas input yang akan dipindai.
  • -o: Folder output yang otomatis memilah hasil carving berdasarkan ekstensi (png/, zip/, pdf/, dan laporan audit.txt).
Kapan dipakai · binwalk gagal mengekstrak berkas secara bersih, atau saat memulihkan banyak file dari raw disk image / memory dump.
Kombinasi piping 
$foremost -i disk.dd -o carved/ && cat carved/audit.txt

Menjalankan pemulihan file dan langsung mencetak ringkasan file apa saja yang ditemukan.

03

dd (Offset Slicing)

— Pemotongan File Manual via Offset

Precision Cut
Sintaks siap pakai 
$dd if=gambar_gabungan.jpg of=rahasia.zip bs=1 skip=45820
Fungsi & penjelasan opsi
  • bs=1: Mengatur ukuran blok ke 1 byte agar angka skip sama persis dengan offset desimal dari binwalk.
  • skip=45820: Melewati 45.820 byte pertama dan menyalin sisanya menjadi file baru.
Kapan dipakai · binwalk menunjukkan adanya arsip di offset tertentu tetapi gagal mengekstraknya karena nama/struktur arsip dimodifikasi.
Kombinasi piping 
$binwalk target.png | awk '/Zip/ {print $1}' | xargs -I {} dd if=target.png of=extracted.zip bs=1 skip={}

Otomatis mengambil offset desimal ZIP dari binwalk dan memotongnya ke file extracted.zip.

04

7z / gunzip / zip -FF

— Ekstraksi Paksa & Perbaikan Arsip

Archive Recovery
Sintaks siap pakai 
$7z x arsip_rusak.zip -ooutput_folder/
$zip -FF rusak.zip --out diperbaiki.zip
$gunzip -k disk.flag.img.gz
Fungsi & penjelasan opsi
  • 7z x ... -ofolder/: Jauh lebih toleran daripada unzip saat menghadapi struktur arsip yang terpotong sebagian.
  • zip -FF (fix-fix): Membangun ulang Central Directory arsip ZIP yang rusak.
  • gunzip -k (keep): Mendekompresi .gz tanpa menghapus file terkompresi aslinya.
Kapan dipakai · Muncul galat End-of-central-directory signature not found saat menjalankan unzip, atau saat mendekompresi file .img.gz / .tar.xz.
Kombinasi piping 
$7z l arsip.7z | grep -iE "flag|txt|secret|key"

Mengintip daftar isi arsip (l) tanpa mengekstrak seluruh file raksasa di dalamnya.

05

bulk_extractor

— Pemulihan Cepat Semua Jenis Data

Mass Carving
Sintaks siap pakai 
$bulk_extractor -o hasil_bulk/ disk_image.dd
Fungsi & penjelasan opsi
  • bulk_extractor: Memindai berkas mentah apa pun — disk image, memory dump, atau file gabungan — mencari pola data bernilai forensik secara paralel, seperti alamat email, URL, nomor kartu, dan domain, tanpa perlu memahami struktur filesystem-nya.
  • -o hasil_bulk/: Folder output tempat seluruh laporan (email.txt, url.txt, domain.txt, dan lainnya) disimpan.
  • Jauh lebih cepat dibanding foremost pada image berukuran besar karena memproses secara multi-thread dan tidak bergantung pada struktur partisi yang valid.
Kapan dipakai · Berkas bukti berukuran besar seperti disk image atau memory dump, dan kombinasi binwalk plus foremost sudah dicoba namun belum menemukan petunjuk — gunakan sebagai sapuan menyeluruh tahap akhir.
Kombinasi piping 
$bulk_extractor -o hasil_bulk/ dump.raw && grep -iE 'flag|ctf' hasil_bulk/*.txt

Menjalankan pemindaian penuh lalu langsung menyaring seluruh laporan hasil ekstraksi mencari kata kunci flag.

05
Tahap 05

Arsip Terkunci, Jaringan (PCAP), Disk Image & Memory Dump

Teknik forensik tingkat lanjut untuk membobol arsip ber-password, menganalisis tangkapan paket jaringan, membedah partisi disk serta slack space, dan menginvestigasi RAM.

01

zip2john / john / fcrackzip

— Cracking Password Arsip

Password Crack
Sintaks siap pakai 
$zip2john terkunci.zip > zip.hash && john --wordlist=/usr/share/wordlists/rockyou.txt zip.hash
$fcrackzip -u -D -p /usr/share/wordlists/rockyou.txt terkunci.zip
Fungsi & penjelasan opsi
  • zip2john (juga tersedia 7z2john dan rar2john): Mengekstrak hash enkripsi arsip untuk dipecahkan oleh John the Ripper.
  • fcrackzip -u -D -p: Melakukan serangan kamus (-D) langsung pada file ZIP dan memvalidasi hasil dengan unzip (-u).
  • Keluarga *2john lain yang sepadan: rar2john untuk RAR, pdf2john.pl untuk PDF ber-password, dan ssh2john untuk private key SSH terenkripsi — semuanya menghasilkan hash siap pakai untuk john.
Kapan dipakai · File hasil ekstraksi berupa arsip .zip, .7z, atau .rar yang meminta password tanpa petunjuk di dalam soal.
Kombinasi piping 
$john --show zip.hash | awk -F':' '{print $2}'

Mencetak kata sandi yang sudah berhasil dipecahkan dalam format bersih.

02

tshark

— Investigasi Lalu Lintas Paket (PCAP)

Network Forensics
Sintaks siap pakai 
$tshark -r traffic.pcap -q -z io,phs
$tshark -r traffic.pcap --export-objects "http,http_obj/" -q
Fungsi & penjelasan opsi
  • -z io,phs: Menampilkan Protocol Hierarchy Statistics untuk melihat protokol apa saja yang ada di PCAP dalam hitungan detik.
  • --export-objects "http,folder/": Mengekstrak seluruh file yang diunduh lewat HTTP (gambar, dokumen, skrip) ke folder tujuan.
  • -Y "dns" -T fields -e dns.qry.name: Menampilkan seluruh kueri domain DNS (untuk mendeteksi DNS Exfiltration).
Kapan dipakai · Soal memberikan file .pcap atau .pcapng berisi aktivitas transfer file, login HTTP, atau kueri DNS mencurigakan.
Kombinasi piping 
$tshark -r traffic.pcap -Y "dns.flags.response == 0" -T fields -e dns.qry.name | sort | uniq -c | sort -nr

Mengelompokkan dan menghitung seluruh kueri DNS unik untuk menemukan subdomain pembawa flag/petunjuk.

03

tcpflow

— Rekonstruksi Aliran Sesi TCP

TCP Stream
Sintaks siap pakai 
$tcpflow -r traffic.pcap -o aliran_tcp/
Fungsi & penjelasan opsi
  • tcpflow: Menggabungkan ulang paket-paket TCP yang terpecah menjadi berkas aliran komunikasi utuh per sesi (mirip fitur Follow TCP Stream di Wireshark).
  • -o aliran_tcp/: Menyimpan setiap aliran komunikasi ke berkas terpisah di dalam folder tujuan.
Kapan dipakai · Data flag dikirim melalui koneksi TCP mentah seperti Netcat, FTP, Telnet, atau protokol chat kustom.
Kombinasi piping 
$tcpflow -r traffic.pcap -o aliran_tcp/ && grep -rnEai "flag\{|ctf\{|pico|academy" aliran_tcp/

Merekonstruksi seluruh sesi TCP lalu langsung mencari pola flag di semua file hasil aliran.

04

mmls / fls / icat

— Forensik Disk Image & Slack Space

The Sleuth Kit
Sintaks siap pakai 
$mmls disk.img
$fls -r -d -o 2048 disk.img
$icat -r -o 2048 disk.img 1524 > pulih.txt
$icat -s -o 2048 disk.img 2450 > slack.txt
Fungsi & penjelasan opsi
  • mmls: Menampilkan tabel partisi dan sektor awal (Start Sector) pada berkas .img / .dd.
  • fls -r -d -o 2048: Mendaftar seluruh file secara rekursif (-r) termasuk file yang sudah dihapus (-d) pada partisi dengan offset sektor 2048.
  • icat -r: Mengekstrak isi berkas terhapus berdasarkan nomor inode-nya.
  • icat -s: Mengekstrak area Slack Space (ruang sisa di akhir sektor blok penyimpanan file, seperti pada soal UnforgottenBits).
Kapan dipakai · Soal memberikan file .img, .dd, atau .iso dengan petunjuk file terhapus atau data tersembunyi di slack space.
Kombinasi piping 
$fls -r -o 731136 disk.flag.img | grep -iE "flag|secret|txt|bmp|note|history"

Memindai seluruh struktur direktori disk image dan menyaring berkas penting milik pengguna.

05

losetup + mount

— Mount Disk Image Seperti Flashdisk

Disk Mounting
Sintaks siap pakai 
$sudo mkdir -p /mnt/ctf_disk
$sudo losetup -Pf --show disk.flag.img
$sudo mount -o ro /dev/loop0p3 /mnt/ctf_disk
Fungsi & penjelasan opsi
  • losetup -Pf --show: Menghubungkan berkas disk image ke perangkat loop Linux sekaligus memindai partisi di dalamnya (-P).
  • mount -o ro: Memasang partisi dalam mode Read-Only agar integritas bukti forensik tidak berubah.
Kapan dipakai · Ingin menjelajahi direktori /home, .bash_history, email, dan log di dalam disk image memakai perintah standar find, ls, dan grep.
Kombinasi piping 
$find /mnt/ctf_disk/home /mnt/ctf_disk/root -maxdepth 3 2>/dev/null

Langsung memetakan seluruh berkas pengguna dan riwayat tersembunyi di dalam partisi yang sudah di-mount.

06

vol (Volatility 3)

— Investigasi Memory Dump (RAM)

Memory Forensics
Sintaks siap pakai 
$vol -f memory.raw windows.pslist
$vol -f memory.raw windows.cmdline
$vol -f memory.raw windows.dumpfiles --virtaddr 0x8a123456
Fungsi & penjelasan opsi
  • windows.pslist / windows.pstree: Menampilkan daftar proses aktif saat RAM diambil.
  • windows.cmdline: Menampilkan argumen baris perintah yang dijalankan tiap program (sering memuat path file flag).
  • windows.filescan & windows.dumpfiles: Mencari objek file di memori dan mengekstraknya kembali ke disk.
  • windows.hashdump & windows.netscan: Mengekstrak hash password user & koneksi jaringan aktif.
Kapan dipakai · Berkas tantangan berukuran ratusan MB hingga beberapa GB (.raw, .vmem, .dmp) dengan skenario sistem yang diretas saat sedang menyala.
Kombinasi piping 
$vol -f memory.raw windows.filescan | grep -iE "flag|desktop|documents|secret|zip|txt"

Memindai seluruh berkas yang terbuka di memori dan menyaring folder pribadi pengguna.

07

hashid

— Mengenali Jenis Hash Sebelum Cracking

Hash ID
Sintaks siap pakai 
$hashid -m '5f4dcc3b5aa765d61d8327deb882cf99'
Fungsi & penjelasan opsi
  • hashid: Mencocokkan panjang dan pola karakter sebuah string dengan ratusan format hash yang dikenal, seperti MD5, SHA-1, NTLM, dan bcrypt, untuk menebak algoritme yang dipakai.
  • -m: Menampilkan nomor mode hashcat yang sesuai (misalnya -m 0 untuk MD5) agar bisa langsung dipakai pada perintah hashcat.
  • Alternatif: hash-identifier adalah versi interaktif lama, dipakai jika hashid belum terpasang.
Kapan dipakai · Soal memberikan string hash mentah tanpa keterangan jenisnya sebelum proses cracking dimulai — mengenali algoritme yang tepat jauh lebih efisien daripada mencoba semua mode secara membabi buta.
Kombinasi piping 
$hashid -m target_hash.txt | tee dugaan_mode.txt && hashcat -m 0 -a 0 target_hash.txt /usr/share/wordlists/rockyou.txt

Menebak mode hash lebih dulu lalu langsung mencobanya dengan hashcat memakai wordlist rockyou sebagai alternatif john.

Tahap 06

Forensik Artefak Sistem, Git Repository, Database & Log

Kategori wajib dalam kompetisi CTF modern untuk memulihkan riwayat kode yang dihapus di Git, membedah database SQLite, serta membaca log sistem Windows & Linux.

01

git log / fsck

— Pemulihan Commit & Blob Terhapus

Git Forensics
Sintaks siap pakai 
$git log -p --all
$git fsck --full && git show <HASH_BLOB>
Fungsi & penjelasan opsi
  • git log -p --all: Menampilkan seluruh riwayat perubahan (diff) dari awal hingga akhir di semua branch.
  • git fsck --full: Menemukan dangling commits atau dangling blobs yang sudah dihapus dengan git reset namun objeknya masih tersimpan di folder .git.
Kapan dipakai · Direktori ekstraksi mengandung folder tersembunyi .git/ dan pembuat soal menghapus flag pada commit terbaru.
Kombinasi piping 
$git log -p --all | grep -iE "flag|ctf|pico|academy|password|secret"

Memindai seluruh baris kode yang pernah ditambahkan atau dihapus di sepanjang sejarah repository Git.

02

sqlite3

— Bedah Database SQLite & Browser

Database
Sintaks siap pakai 
$sqlite3 database.db ".tables"
$sqlite3 database.db ".dump"
Fungsi & penjelasan opsi
  • ".tables": Menampilkan daftar seluruh nama tabel di dalam file .db / .sqlite.
  • ".dump": Mengekspor seluruh struktur tabel dan isi datanya menjadi teks SQL yang mudah dicari.
Kapan dipakai · Perintah file mendeteksi SQLite 3.x database (sering berasal dari artefak browser Chrome/Firefox History atau Cookies).
Kombinasi piping 
$sqlite3 History ".dump" | grep -iE "flag|ctf|pico|academy|http"

Mengekstrak seluruh riwayat kunjungan URL dan data tersimpan dari database SQLite.

03

evtx_dump / hivexget

— Forensik Log Event & Registry Windows

Windows Artifacts
Sintaks siap pakai 
$evtx_dump Security.evtx > security_logs.xml
$hivexget NTUSER.DAT "Software\Microsoft\Windows\CurrentVersion\Run"
Fungsi & penjelasan opsi
  • evtx_dump: Mengonversi berkas biner Windows Event Log (.evtx) menjadi XML yang bisa dibaca manusia.
  • hivexget: Membaca kunci dan nilai spesifik dari berkas Windows Registry Hive (NTUSER.DAT, SYSTEM, SAM).
Kapan dipakai · Soal memberikan folder artefak Windows seperti System32/winevt/Logs atau file registry pengguna.
Kombinasi piping 
$evtx_dump Security.evtx | grep -iE "4624|4688|powershell|flag|ctf|academy"

Menyaring Event ID login sukses (4624), pembuatan proses baru (4688), atau perintah PowerShell berbahaya.

04

utmpdump / journalctl

— Forensik Log Login & Systemd Linux

Linux Artifacts
Sintaks siap pakai 
$utmpdump /var/log/wtmp
$journalctl --file=system.journal --no-pager
Fungsi & penjelasan opsi
  • utmpdump: Menerjemahkan log biner riwayat login Linux (wtmp, btmp, utmp) menjadi teks terbaca.
  • journalctl --file=...: Membaca file jurnal systemd biner (.journal) hasil ekstraksi dari disk image Linux.
Kapan dipakai · Soal meminta melacak alamat IP penyerang yang berhasil login SSH atau perintah yang dijalankan layanan systemd.
Kombinasi piping 
$utmpdump wtmp | grep -iE "pts|ssh|flag|ctf"

Menampilkan sesi terminal SSH beserta IP asal penyerang.

05

apktool / jadx

— Membongkar Berkas APK Android

Android Forensics
Sintaks siap pakai 
$apktool d aplikasi.apk -o hasil_decompile/
Fungsi & penjelasan opsi
  • apktool d: Mendekompilasi berkas APK, yang sejatinya adalah arsip ZIP, menjadi resource asli dan kode smali, yakni bytecode Dalvik yang terbaca manusia.
  • jadx -d hasil_jadx/ aplikasi.apk: Alternatif yang mendekompilasi langsung menjadi kode semu mirip Java, umumnya lebih mudah dibaca untuk menelusuri logika penyimpanan flag.
  • unzip -o aplikasi.apk -d raw/: Cara cepat tanpa dekompilasi penuh untuk langsung melihat isi assets/ dan res/raw/, tempat berkas tersembunyi sering diselipkan.
Kapan dipakai · Soal memberikan berkas .apk — flag umumnya tersembunyi di strings.xml, pada konstanta kode smali atau Java, atau sebagai berkas tambahan di dalam folder assets/.
Kombinasi piping 
$apktool d aplikasi.apk -o out/ && grep -rnEoa "[a-zA-Z0-9_]+\{[a-zA-Z0-9_@!?-]+\}" out/

Mendekompilasi seluruh APK lalu langsung menerapkan pola regex flag ke semua berkas hasil dekompilasi sekaligus.
